## CPU run in a fresh output directory

From the **project directory**, choose a fresh directory to preserve the committed reference results:

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
PY=/root/v016-sonarts-env/bin/python
EXP=experiments/v020-evidence-fidelity
REF=results/v020-evidence-fidelity
export V020_OUT="$PWD/results/v020-reproduction-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$V020_OUT"
cp -a "$REF/sources" "$V020_OUT/"
cp "$REF/data-selection.json" "$V020_OUT/"
$PY "$EXP/acquire.py"
$PY "$EXP/run_audit.py"
$PY "$EXP/certificates.py"
$PY "$EXP/bounds_audit.py"
$PY "$EXP/analyze.py"
```

`acquire.py` requires source metadata already copied above; it does not need GPU. Primary labels are generated by declared NumPy rules on unmodified ECG. Official clinical QA metadata are separate. `run_audit.py` reuses completed context files **inside the chosen output directory**; choose a fresh directory to measure timings anew. `protocol.json` was frozen before inspecting raw numeric values; its SHA-256 is in cpu-complete.json. Output timing values need not be byte-identical across runs. CPU predictions, exact certificates and data hashes should agree. Data/bootstrap seed is 20261102; the GPU server had seed=None (no explicit seed), with greedy temperature=0 decoding; cross-device GPU bitwise identity is not promised. Full-resolution bytes count one channel except the two cross-channel query types. All 1,920 raw access traces are also losslessly stored in refinement-traces.jsonl.gz.

`certificates.py` tests 280 exact boundary/accounting cases and searches a bounded family of counterfactual permutations of record 104. These diagnostic alternatives stay in memory. Each successful witness has identical actual stored representation bytes and differing exact answers; a failed witness search means no conclusion. They are not added as extra real-data subjects.

To audit official QA parquet metadata, set `PYTHONPATH=/root/v020-extra` and use pandas.read_parquet on `data/v020-evidence-fidelity/official-qa/...`. The reference output includes schema, counts and one original example per file. The event interval annotations in numeric-evidence-annotations.jsonl.gz are evaluation-only; retrieval policies never load them.

## Sonar-TS + local Qwen3-8B

Existing local Qwen weights must be available at `/root/autodl-tmp/cf-run/models/qwen3-8b`; no fallback paid API exists. `serve.sh` is the exact local BF16 server configuration. Start it in a separate terminal only when GPU use is intended; wait for the localhost server to become ready. Shut down that server after the run. No need to keep it running for CPU analysis.

```bash
bash experiments/v020-evidence-fidelity/serve.sh
```

In another terminal, keep the same V020_OUT from the CPU run:

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
export V020_DB_DIR="$PWD/data/v020-evidence-fidelity/sonar-databases-reproduction"
PY=/root/v016-sonarts-env/bin/python
$PY experiments/v020-evidence-fidelity/sonar_bridge.py prepare
$PY experiments/v020-evidence-fidelity/sonar_bridge.py run
```

The fixed selection is two lexicographic native Global Aggregation IDs followed by six predefined ECG query types on full/PAA64 views. The native IDs are fixed independently of model outcomes. If no native case executes successfully the unified run stops; original native cases both scored exactly correct. DB loading preserves fractional seconds. SQLite timestamps have an artificial relative-time origin, not invented acquisition dates. PAA question text states the 64-sample hold convention. Official planner/skills/generation/execution/retry/postprocessing remain unchanged; only local client, data adapter and read tracing are added. The full system is called **Sonar-TS + local Qwen3-8B**, never the official DeepSeek performance.

`sonar/traces/<id>/` saves prompts, raw responses, generated code, execution failures/retries, SQL return traces, planning and final answers. If a case record exists it is resumed without issuing duplicate LLM calls. Use a new V020_OUT and V020_DB_DIR for an independent rerun. Official rel_acc and strict equality are separately recorded. Compressed-table truth uses a 64-point held reconstruction, not a naive compressed-row count. SQL returned rows are not measured pages scanned. Full SQL/variable traces include signal arrays and remain local. publish_traces.py writes public-sql/ audit versions with queries, counts and payload hashes; .gitignore excludes the original raw-payload traces. Query latencies include observational trace serialization overhead.

The native TT-SAX CPU smoke additionally needs the existing v019 CSV `L3_T1_Composite_Trend_00001.csv`. Reacquire it with the existing v019 pinned-data instructions if absent; then run:

```bash
$PY experiments/v020-evidence-fidelity/symbolic_smoke.py
$PY experiments/v020-evidence-fidelity/finalize.py
$PY experiments/v020-evidence-fidelity/publish_traces.py
```

`finalize.py` summarizes actual Sonar records, emits evaluation-only event annotations and environment metadata. Run it while the local server is active only if a current GPU memory snapshot is needed; observed snapshots are not certified peaks. Afterward stop the server you started. It never stops other jobs.

## Interpretation and limitations

- Fixed-view decoding equality is an operational answer-preservation result, not optimal information recoverability. MinMax UNKNOWN and PLA loose bounds are inconclusive, not proofs of loss.
- Reference TT-SAX encoding and literal-regex smoke are not the paper's full natural-language search evaluation. Level-only decoding is explicitly diagnostic and excludes its trend track from answering.
- MinMax+Sum tree and EventIndex are exact on this declared query family. Their offline complete-source scans, all tree levels and event-index workload specificity are part of the baseline.
- Raw broker bytes are unique scalar values fetched; node reads count actual logical accesses. No physical disk I/O was profiled. Already decoded fixed-view answer timing cannot establish deployed compression speedup.
- Eight record clusters, not 240 independent subjects; bootstrap confidence intervals resample whole records. The report does not infer clinical or all-domain generalization, nor superiority over unexecuted models.
