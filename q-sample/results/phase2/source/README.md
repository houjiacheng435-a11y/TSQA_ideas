# 实验实际使用的源码

- `main/`：69 项冻结矩阵的四个数值计算源文件，以及当时的批量运行器。
- `development/`：事件宽度默认值仍为 384 的开发版，与全部 7 项开发记录的源文件 SHA256 一致。
- `encoder-probe/`、`budget-probe/`：两个诊断程序当时使用的版本，与各配置中记录的脚本 SHA256 一致。
- `checksums.json`：这些文件的逐文件哈希。

实验完成后，项目根目录的运行程序补充了独立输出目录参数、完整矩阵续跑时保留原完成记录、预算诊断不依赖汇总文件等复现保护。数值模型、数据生成、训练与采样算法没有因此改变。此处保留运行时原版，避免把后续命令行修复误当成原实验源码。
