# 来源与许可

本目录保留 mrtan 发布的 NLQTSBench、NLQTSBench-train、NLQTSBench-train-v2 官方元数据快照（Apache-2.0）。作者与构造说明见各数据集原始 README 和 https://github.com/Atlamtiz/Sonar-TS 。

原始任务、自然语言问题、答案和官方划分未改写。API/tree 响应仅重新排版为 JSON，用于完整文件指纹审计。具体 revision 与 SHA256 见上级 provenance.json；本地分析另存 audit_results.json。

本目录不包含原始 CSV 或模型权重。LICENSE 取自固定版本 Sonar-TS 官方代码仓库，供同许可材料一并分发。
